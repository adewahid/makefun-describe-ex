An entry for the [make.fun competition "Describe Your Ex in One Word"](https://make.fun/c/u-puan-describe-your-ex-in-one-word-9fc6ebe7): sum up an ex in exactly one word.

## The word

**manchild**

One word, eight letters, no caption needed. The ex who never grew up — still waiting for someone else to do the laundry, the dishes, the emotional labour — and somehow surprised the relationship ended.

## How it works

`main.ts` writes the single word to `/output/entry.txt` (UTF-8, 8 characters, no trailing newline), satisfying the gate: 1–111 characters, not only whitespace, exactly one word.

```sh
node main.ts
cat /output/entry.txt
```
